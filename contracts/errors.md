# 错误码表 / Error Codes

响应统一为 `{code, message, data}`；`code=0` 成功。错误返回真实 HTTP 状态码 + 5 位业务码（前 3 位 = HTTP 状态码）。

| HTTP | code  | 含义 |
|------|-------|------|
| 400  | 40001 | 参数校验失败 |
| 400  | 40002 | ad 解锁缺少 adRewardToken |
| 400  | 40003 | 头像上传 contentType 不支持（仅 jpeg/png/webp） |
| 401  | 40101 | 未登录 / accessToken 无效或过期 |
| 401  | 40102 | refreshToken 无效 |
| 401  | 40103 | 回调验签失败 |
| 402  | 40201 | 金币余额不足 |
| 403  | 40301 | 剧集已锁定（data: priceCoins, vipAvailable, adAvailable） |
| 403  | 40302 | 无权限 |
| 404  | 40401 | 资源不存在 |
| 409  | 40901 | 账号已绑定 |
| 409  | 40902 | 今日已签到 |
| 409  | 40903 | 任务不可领取（含 /rewards/{taskId}/claim：未达成、已领取、宝箱未解锁） |
| 409  | 40904 | 重复请求（幂等冲突） |
| 409  | 40905 | 剧已上线，不能再设置上线提醒 |
| 422  | 42201 | 购买凭证校验失败 |
| 422  | 42202 | 优惠券不可用（已用、过期、未达门槛、不适用该档位或渠道） |
| 429  | 42901 | 请求过于频繁（按设备 + IP 限流） |
| 500  | 50001 | 服务器内部错误 |
| 501  | 50101 | 功能尚未实现（bind、ad/vip 解锁） |
| 503  | 50301 | 依赖服务不可用 |

说明：40902 现在也用于 `POST /rewards/checkin:YYYY-MM-DD/claim`（今日已签到）。点赞、收藏、提醒的 POST/DELETE 都是幂等的，重复调用返回 200，不报错。
